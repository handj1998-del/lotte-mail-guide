‘Outlook 웹으로 열기’는 전용 Outlook 탭 하나를 계속 다시 쓰며, 누를 때마다 그 탭이 받는 사람·제목·본문(텍스트, 서식 없음)이 채워진 새 작성 창으로 바뀝니다(그 탭에서 쓰던 내용은 저장되지 않을 수 있으니 먼저 보내거나 임시 저장하세요). 이 브라우저에서 Outlook에 로그인되어 있어야 하며, 본문이 길면 잘릴 수 있으니 그때는 복사 버튼을 사용하세요. 보내기는 Outlook에서 직접 누릅니다.

Outlook으로 보내기 준비 서식(굵게·링크) 그대로 넣기 · 자동으로 보내지 않습니다
  1. Outlook 웹 + 본문 복사를 누르면 본문이 복사되고, 브라우저에 받는 사람·제목이 채워진 새 메일 창이 열립니다.
  2. 본문 칸을 클릭하고 Ctrl+V 로 본문에 붙여넣기 하세요.
  3. 내용을 확인하고 Outlook에서 직접 보내기를 누릅니다.
확장 프로그램으로 넣기 이미 열린 Outlook 웹 작성 창에 받는 사람·제목·본문(서식 포함)을 넣습니다
  1. Outlook 웹에서 새 메일을 엽니다. (확장 프로그램 ‘롯데 안내메일 넣기’ 설치 필요 — 사용방법.txt 참고)
  2. 아래 확장 프로그램용 복사를 누릅니다.
  3. Outlook 탭의 오른쪽 아래 안내메일 넣기 버튼(또는 Alt+Shift+M)을 누릅니다.
  4. 들어간 내용을 확인하고 Outlook에서 직접 보내기를 누릅니다. (확장 프로그램은 절대 자동으로 보내지 않습니다)

사용 순서: 웹메일 ‘메일 쓰기’ → 받는사람 복사 → 받는 사람 칸에 붙여넣기(Ctrl+V) → 제목 복사 → 제목 칸에 붙여넣기 → 전체 복사 → 본문 칸에 붙여넣기.
‘전체 복사’는 본문을 서식(줄바꿈·굵게) 있는 형태와 일반 텍스트 두 가지로 함께 복사합니다. 서식이 이상하게 붙으면 ‘본문 복사’(텍스트만)를 사용하세요.
‘mailto로 열기’는 웹메일이 아니라 PC의 기본 메일 프로그램을 엽니다. Windows ‘메일’ 앱이 계정 추가를 요구하면 사용방법.txt의 기본 앱 설정 팁을 보거나 ‘Outlook 웹으로 열기’를 사용하세요.
